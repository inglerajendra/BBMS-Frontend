# Billing Management System (BBMS)

A full-stack web application designed to help small and medium-sized businesses manage customers, invoices, expenses, payments, and business financial information from a centralized dashboard.

The system provides a clean interface for managing day-to-day billing operations and tracking important business metrics such as revenue, expenses, unpaid invoices, and profit/loss.

---

## 🚀 Features

### 📊 Dashboard

- Overview of important business metrics
- Total customers
- Total invoices
- Total revenue
- Total expenses
- Unpaid invoices
- Profit/Loss
- Recent invoices
- Quick access to invoice actions

### 👥 Customer Management

- Add new customers
- View customer details
- Edit customer information
- Delete customers
- View customer-related invoices

### 🧾 Invoice Management

- Create invoices
- Select customers
- Add multiple invoice items
- Automatically calculate item subtotals
- Automatically calculate invoice total
- Track transaction status
- View invoice details
- Edit invoices
- Delete invoices
- Generate/download invoice PDF

### 💰 Expense Management

- Add business expenses
- Record expense amount
- Track payment status
- Edit expenses
- Delete expenses
- View expense records

### 🔐 Authentication

- Secure user authentication
- JWT-based authentication
- Protected application routes
- Password hashing using bcrypt
